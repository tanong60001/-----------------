# วิธีติดตั้งฐานข้อมูลระบบบันทึกน้ำมัน

ระบบนี้ใช้ตารางใหม่ชื่อ `fuel_transactions` จึงไม่กระทบข้อมูลขาย สต็อกสินค้า หรือบัญชีเดิมของร้าน

## ขั้นตอนติดตั้ง

1. เข้าสู่ [Supabase Dashboard](https://supabase.com/dashboard) และเลือกโปรเจกต์ฐานข้อมูลของร้าน
2. เปิดเมนู **SQL Editor** ทางซ้าย แล้วกด **New query**
3. เปิดไฟล์ `migrations/fuel_inventory.sql` ที่อยู่ในโฟลเดอร์โปรแกรม
4. คัดลอก SQL ทั้งหมดในไฟล์ไปวางใน SQL Editor
5. กด **Run** และรอจนขึ้นข้อความ `Success`
6. ปิดแล้วเปิดโปรแกรมใหม่ หรือกดรีเฟรชหน้าเว็บ
7. เข้าเมนู **การเงิน → บันทึกน้ำมัน**

หากติดตั้งสำเร็จ หน้าบันทึกน้ำมันจะแสดงยอดคงเหลือเป็น `0 ลิตร` และสามารถกด **รับน้ำมันเข้า** ได้ทันที

## ทดสอบแบบเร็ว

1. กด **รับน้ำมันเข้า** เลือกชนิดน้ำมัน และใส่ `100` ลิตร
2. กด **เติมน้ำมันให้รถ** ใส่ทะเบียน คนขับ และ `20` ลิตร
3. ยอดคงเหลือควรเป็น `80 ลิตร`

ระบบฐานข้อมูลจะไม่ยอมให้บันทึกยอดเติมรถเกินน้ำมันคงเหลือ แม้มีหลายเครื่องบันทึกพร้อมกัน

## สิทธิ์การใช้งาน

- เมนูนี้ใช้สิทธิ์เดียวกับเมนู **รายจ่าย** (`can_exp`)
- ผู้ใช้งานที่มีสิทธิ์รายจ่ายสามารถรับเข้าและบันทึกเติมรถได้
- ปุ่มลบรายการจะแสดงเฉพาะผู้ดูแลระบบ เพื่อป้องกันยอดย้อนหลังคลาดเคลื่อน

## ข้อมูลที่บันทึก

- ประเภท: รับเข้า หรือเติมรถ
- น้ำมันดีเซลและจำนวนลิตร
- วันและเวลาที่เกิดรายการ
- ทะเบียนรถและชื่อคนขับ ณ เวลาที่เติม
- ผู้จำหน่ายสำหรับรายการรับเข้า
- เลขไมล์และหมายเหตุ (ไม่บังคับ)
- ชื่อผู้ใช้งานที่เป็นผู้บันทึก

ทะเบียนรถและชื่อคนขับถูกเก็บเป็นข้อมูล ณ เวลาทำรายการ ดังนั้นหากภายหลังเปลี่ยนคนขับ ประวัติเก่าจะยังคงถูกต้อง

## การแก้ปัญหา

หากหน้าโปรแกรมแจ้งว่าไม่พบฐานข้อมูล:

1. ตรวจว่า SQL รันจนจบโดยไม่มีบรรทัดสีแดง
2. ไปที่ **Table Editor** และตรวจว่ามีตาราง `fuel_transactions`
3. รีเฟรชโปรแกรมด้วย `Ctrl + F5`
4. หากยังไม่สำเร็จ ให้เปิด SQL Editor แล้วรันไฟล์เดิมซ้ำได้ ไฟล์ถูกออกแบบให้ติดตั้งซ้ำโดยไม่ลบข้อมูลเดิม
